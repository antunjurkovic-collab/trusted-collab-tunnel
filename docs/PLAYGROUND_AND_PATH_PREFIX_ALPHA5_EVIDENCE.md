# Playground and URL-Path-Prefix Alpha.5 Evidence

Status: alpha.5 path-prefix routing blocker reproduced; test/docs only

Evidence date: 2026-07-28

## Scope

This checkpoint investigates one temporary browser WordPress Playground
installation reported by the owner and two controlled local comparisons. It
does not classify all Playground deployments or alter the plugin.

The exact retained artifact remained:

```text
dist/trusted-collab-tunnel-3.0.0-alpha.5.zip
SHA-256 e68985cb8e315385052d0632d745969e759bd53d5bc5e70649891fc9b5833869
```

No alpha.5 runtime source, packaged file, build manifest, draft artifact, or
cache behavior changed.

## Temporary Browser Playground Observation

The owner installed alpha.5 in the temporary browser scope:

`https://playground.wordpress.net/scope:funny-modern-village`

The administrator-initiated Doctor observed:

- valid root discovery;
- canonical M-Sitemap and homepage M-URL JSON;
- exact strong ETags, Content-Digest, Content-Length, profile links,
  `no-transform`, conditional behavior, HEAD metadata, and repeated
  stability;
- identity bytes even when gzip was advertised;
- `200` rather than the expected `406` when identity was explicitly
  prohibited; and
- `404` for two non-home pretty M-URLs advertised by the M-Sitemap.

The scope later returned `404` outside the active browser session. WordPress
Playground scopes are temporary browser/service-worker environments, not
durable public origins, so this observation is exploratory evidence rather
than a provider compatibility classification.

The identity-prohibition result is also not reliable browser evidence.
Browser Fetch treats `Accept-Encoding` as a forbidden request header, so a
page script cannot be assumed to have transmitted the Doctor's requested
value. The successful local external-validator result below confirms the
alpha.5 `406` behavior when the header reaches WordPress.

Relevant upstream descriptions:

- <https://wordpress.github.io/wordpress-playground/about/>
- <https://wordpress.github.io/wordpress-playground/developers/architecture/browser-scopes/>
- <https://fetch.spec.whatwg.org/#forbidden-request-header>

## Attribution

For a pretty non-home M-URL, `includes/Endpoint.php` parses the raw
`REQUEST_URI`, captures everything before `/llm/`, and passes that path to
`home_url()`. Under this lane:

```text
home URL:      http://127.0.0.1:8095/subsite
request path:  /subsite/2026/07/28/<slug>/llm/
captured path: /subsite/2026/07/28/<slug>/
```

The installation prefix is therefore included once by the captured request
path and again by `home_url()`. The resulting C-URL cannot resolve to the
post, and alpha.5 fails closed with `404`. The query form succeeds because
WordPress supplies the already resolved post directly.

This is a concrete alpha.5 adapter defect for WordPress installations whose
public home URL has a path prefix. It is not a Draft-03 protocol defect,
cache-provider incompatibility, compression condition, PHP/WASM limitation,
or general Playground failure.

The external validator constructed the correct prefixed requests, but its
summary DTO reduced `base_url` to the URI authority. That reporting-only gap
is separately deferred; it did not cause the observed requests or route
failures.

## Decision Boundary

Alpha.5 remains valid for the already accepted root-hosted controlled lanes,
but it must not claim support for path-prefixed WordPress installations.
Temporary browser Playground results must not be used as durable public-path
compatibility evidence.

A repair requires a separately authorized generation with:

1. one shared, bounded removal of the configured home-path prefix before
   C-URL reconstruction;
2. no change to Draft-03 identity, ETag, schema, or cache semantics;
3. deterministic root, `/subsite`, and Playground-scope route fixtures;
4. exact pretty and query-form post/page tests;
5. external-validator summary preservation of a configured base path; and
6. a new package/version and full evidence gate.

No repair, repackaging, provider adapter, or release action is authorized by
this checkpoint.
